# 帧格

本机运行的视频画面拼图网页。每个视频只生成一张图片。设置网格行列数后，程序会在整段视频中均匀选取对应数量的帧；若视频帧数少于格子数，则使用全部帧并留下空位。

## 运行

需要 Node.js 20 或更新版本。

```powershell
npm install
npm start
```

打开 <http://localhost:4173>。服务只监听本机。支持设置 1–10 行、1–10 列、512/1024/2048/4096 像素的正方形输出尺寸，以及 JPG/PNG 格式。画面会等比缩放并补边，可直接下载生成的图片。

“画面间距”可在 0% 到 4% 之间调整。每格按视频原始宽高比排列，画面之间只保留设定的间隔；正方形画布多余的空间放在拼图外围。生成结果后修改滑块并点击“更新间距”，会直接重排当前拼图，已删除的帧保持不变。

结果生成后点击“删除帧”或图片，点选不需要的格子，再应用删除。其余帧会重新排布；“恢复全部帧”可重新生成最初的抽帧结果。

上传文件上限为 2 GB。处理结果临时保留约一小时，页面刷新后可继续查看同一次处理结果。

运行 `npm test` 可用测试视频检查均匀抽帧、单图输出和最终图片尺寸。
